# 指标定义与赋值标准

本文档定义了知识库中指标的标准。
 

## 指标定义

### 1. confidence_weight（置信度权重）

**定义**：该知识在消歧推理中的可靠性，反映应用时正确解决歧义的概率。

**赋值标准**（按优先级）：

1. **有验证数据时**：使用实际正确率
   - 正确率 = 正确应用次数 / 总应用次数
   - 示例：规则应用100次，正确85次 → confidence_weight = 0.85

2. **无验证数据时**：基于来源类型
   - **经典理论/原则**（语言学经典、领域公理）：0.85-0.95
   - **专家共识**（领域专家一致认可）：0.75-0.85
   - **经验总结**（基于实践总结）：0.65-0.75
   - **实验性/假设**（未经验证）：0.50-0.65

**赋值方法**：
- 有数据：直接使用数据
- 无数据：根据来源类型选择对应范围的值

**示例**：
- "最近指代原则"（语言学经典理论）→ 0.85
- "领域上下文优先"（经验总结）→ 0.70
- 某规则验证100次，正确80次 → 0.80

### 2. usage_frequency（使用频率）

**定义**：该知识在实际消歧任务中被使用的频率。

**赋值标准**（按优先级）：

1. **有使用统计时**：使用实际频率
   - 频率 = 使用次数 / 同类知识总使用次数
   - 示例：在100次指代消歧中，该规则使用80次 → usage_frequency = 0.80

2. **无使用统计时**：基于优先级和适用场景
   - **高优先级（priority=1）** + **多场景（≥3种）**：0.80-0.90
   - **高优先级（priority=1）** + **少场景（1-2种）**：0.70-0.80
   - **中优先级（priority=2）** + **多场景**：0.60-0.70
   - **中优先级（priority=2）** + **少场景**：0.50-0.60
   - **低优先级（priority≥3）**：0.30-0.50

**赋值方法**：
- 有统计：直接使用统计结果
- 无统计：根据priority和applicable_scenarios数量选择

**示例**：
- REF-001（priority=1，2种场景）→ 0.75
- REF-002（priority=2，1种场景）→ 0.55
- 某规则在100次任务中使用60次 → 0.60

### 3. frequency（术语频率）

**定义**：术语在软件工程文本中的出现频率。

**赋值标准**：

1. **有语料库统计时**：使用实际频率
   - 频率 = 出现次数 / 总词数（或每1000词出现次数归一化）

2. **无统计时**：基于经验判断
   - **极高频**（几乎每篇文档都出现）：0.90-1.0
   - **高频**（经常出现）：0.70-0.90
   - **中频**（偶尔出现）：0.50-0.70
   - **低频**（很少出现）：0.30-0.50

**示例**：
- "接口"（极高频术语）→ 0.95
- "模块"（高频术语）→ 0.85

## 实际操作指南

### 步骤1：收集数据（如果有）

- 验证数据：记录规则/术语的应用次数和正确次数
- 使用统计：记录知识条目的实际使用次数
- 语料库统计：统计术语在语料库中的出现频率

### 步骤2：赋值

**有数据时**：
- confidence_weight = 正确率（从验证数据计算）
- usage_frequency = 使用频率（从使用统计计算）
- frequency = 出现频率（从语料库统计计算）

**无数据时**：
- 根据来源类型选择confidence_weight
- 根据priority和场景数量选择usage_frequency
- 根据经验判断选择frequency

### 步骤3：定期更新

- 随着数据积累，用实际数据替换估计值
- 建议每季度或每半年更新一次

## 简化后的metadata

只保留必要的字段：

```json
{
  "source": "来源类型（linguistic_principle/expert_consensus/empirical/domain_terminology等）",
  "last_updated": "最后更新时间（YYYY-MM-DD）"
}
```

**source字段说明**：
- `linguistic_principle`: 语言学经典理论/原则
- `expert_consensus`: 专家共识
- `empirical`: 经验总结
- `domain_terminology`: 领域术语
- `real_requirement_document`: 真实需求文档
- `classic_case`: 经典案例

## 示例

### 规则示例

```json
{
  "id": "REF-001",
  "confidence_weight": 0.85,  // 语言学经典理论
  "metadata": {
    "source": "linguistic_principle",
    "usage_frequency": 0.75,  // priority=1, 2种场景
    "last_updated": "2024-01-20"
  }
}
```

### 术语示例

```json
{
  "id": "TERM-001",
  "definitions": [
    {
      "confidence": 0.90,  // 标准术语定义
      ...
    }
  ],
  "frequency": 0.95,  // 极高频术语
  "metadata": {
    "source": "domain_terminology",
    "last_updated": "2024-01-20"
  }
}
```

## 注意事项

1. **不要随意填写**：所有值都应该有依据（数据或明确标准）
2. **记录依据**：建议在注释中记录赋值依据
3. **定期更新**：随着数据积累，用实际数据替换估计值
4. **保持一致性**：同类知识使用相同的赋值标准
